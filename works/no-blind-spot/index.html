COOPERATIVE BOARD GAME

NO BLIND SPOT.

8方向の脅威に、ひとつの作戦を。

VRChatGame Design / Unity / UdonSharp1–6 Players
OVERVIEW

偶然を織り込んだ、協力。

8方向から現れる敵に対して、プレイヤー全員で12枚の作戦カードを選択。2枚がランダムに失われ、残り10枚もランダムな順番で実行される。思いどおりにいかない作戦を、仲間と組み立てる協力ゲームです。

Role
Game Design / Unity / UdonSharp / UI / Playtesting
Tools
Unity / UdonSharp / VRChat SDK
Players
1–6
Platform
VRChat
PLAY IN MOTION

25 seconds in the world.

GAMEPLAY / 00:25 / NO AUDIO

実際のプレイ映像。選択したカードに沿って射撃と敵処理が進行します（音声なし）。

01 / CHALLENGE → SOLUTION → RESULT

Designing the experience

01

Challenge

「出すだけ」から、作戦へ。

初期版では「配られたカードを出すだけ」になり、作戦を立てている感覚が弱いことが課題でした。

02

Solution

不確実性を、設計する。

12枚の作戦構築、ランダム除外、監督システムへ再設計。カードの選択と、思いどおりにいかない展開を組み合わせました。

03

Result

最後まで、遊べる一本に。

企画からUnity実装、自動化、UI、プレイテスト、大幅改修までを一貫して制作。VRChat専用の協力ゲームとして完成させました。

DESIGNED FOR VRCHAT

判断はプレイヤーに。
処理はワールドに。

カード選択と作戦立案はプレイヤーに残し、シャッフル・射撃・敵処理・弾薬・スコアを自動化。煩雑な処理を減らし、相談と判断に集中できるようにしました。
